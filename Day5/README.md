# SQLite Student Management System

A menu-driven CRUD application built using Python and SQLite.

## Features

- Add Student
- View Students
- Update Student
- Delete Student
- Prevent Duplicate Records
- SQLite Database Integration

## Technologies Used

- Python
- SQLite3

## How to Run

```bash
python student_record_manager.py
```

## Menu Options

1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Exit
